# Матрица browser E2E

Playwright запускает настоящий Chromium против production-сборок Next.js и
NestJS. Backend использует отдельную PostgreSQL в `tmpfs`; Prisma и база не
подменяются моками.

| Сценарий | UI-действия | Что подтверждает |
| --- | --- | --- |
| Гостевая запись | Выбор услуги, филиала, будущей рабочей даты, свободного слота; заполнение контактов и автомобиля; отправка формы | Каталог и доступность загружаются через API; многошаговая форма работает; запись реально сохраняется; отображается экран успеха |
| Аккаунт и гараж | Регистрация; переход в кабинет; добавление автомобиля; выход; повторный вход | `HttpOnly`-сессия создаётся и удаляется; защищённый кабинет доступен после входа; автомобиль хранится в PostgreSQL и виден в новой сессии |
| Работа администратора | Создание исходной записи через публичный API; вход администратором; поиск записи в панели; подтверждение | Ролевая маршрутизация приводит администратора в `/admin`; запись появляется в панели; допустимый переход `PENDING` → `CONFIRMED` проходит через настоящий API и сохраняется |

Негативные запросы, `401`, `403`, `404`, `409`, конкурентные бронирования и
детальные бизнес-правила покрываются более быстрым Supertest-набором. Browser
E2E намеренно проверяет несколько наиболее ценных сквозных путей, а не повторяет
каждую API-проверку через интерфейс.

## Как обновляется матрица

Автоматически она не обновляется. При добавлении, удалении или изменении
Playwright-сценария разработчик одновременно обновляет таблицу выше и раздел
browser E2E в корневом `TESTING.md`. Матрица нужна как краткий контракт покрытия:
по ней видно, какое пользовательское поведение действительно защищено тестами.

## Назначение файлов

- `user-flows.spec.ts` содержит сценарии и вспомогательные функции для выбора
  будущей рабочей даты и подготовки записи через API.
- `../playwright.config.ts` задаёт Chromium, русский locale, часовой пояс
  приложения, один worker и сохранение trace/screenshot/video при ошибке.
- `../Dockerfile.playwright` устанавливает frontend-зависимости, Chromium и
  системные библиотеки в воспроизводимый Docker-образ.
- `../../../compose.playwright.yaml` поднимает изолированные PostgreSQL, backend,
  frontend и контейнер тест-раннера в правильном порядке.

Команды запуска и очистки приведены в корневом `TESTING.md`.
